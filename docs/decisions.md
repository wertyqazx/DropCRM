# Решения и открытые вопросы

Версия 1.1 · 29 октября 2026 года. Основание – исходные материалы и прямые уточнения владельца проекта. Документ отделяет согласованный объём от предложений по деталям.

## Согласованные решения

| ID | Решение |
| --- | --- |
| D-01 | Модель 2: подключённые поставщики публикуют предложения в общем каталоге, дропшипперы выбирают ассортимент |
| D-02 | Продажа и розничная оплата покупателя происходят во внешнем канале дропшиппера |
| D-03 | Один внутренний заказ относится к одному поставщику |
| D-04 | Наличие и стоимость доставки подтверждает поставщик; после подтверждения дропшиппер оплачивает заказ |
| D-05 | Подписка даёт обеим сторонам доступ к платформе; дополнительно предусмотрена комиссия за сделку |
| D-06 | Регистрация и кабинет администратора входят в объём |
| D-07 | Итоговый интерфейс – интерактивный прототип в Figma, без отдельного веб-приложения |
| D-08 | Новый дизайн должен быть компактным, выглядеть как настоящий продукт, иметь централизованные цвета и обходиться без учебных пометок в интерфейсе |
| D-09 | На текущем этапе готовятся документы и репозиторий; отчёт и пользовательское тестирование отложены до прототипа |

## Рабочие проектные решения

| ID | Правило | Статус |
| --- | --- | --- |
| P-01 | Комиссия 2% со стоимости товаров без доставки, оплачивает дропшиппер | Параметр единого примера в предложенном диапазоне; не окончательный коммерческий тариф |
| P-02 | При подтверждении поставщик резервирует товар; отправка списывает остаток, отмена освобождает резерв | Предложение, необходимое для согласования FR-011–FR-012 |
| P-03 | Просроченная подписка запрещает новые публикации/заказы, но не мешает завершать уже принятые заказы и видеть историю | Предложение по сохранению возможности исполнения обязательств |
| P-04 | Розничная цена округляется до рубля по правилу 0,50 вверх, денежные суммы – до копеек | Единое правило расчётного примера и макетов |

## Ещё не определено

| ID | Вопрос | Последствие |
| --- | --- | --- |
| O-01 | Стоимость, период и условия продления подписок двух ролей | Нельзя подставлять выдуманные утверждённые цены на экран оплаты подписки |
| O-02 | Окончательная ставка, база и плательщик комиссии, учёт эквайринга | Сумма расчётного примера зависит от выбранного параметра |
| O-03 | Срок резерва и действия при его истечении | Значение 24 часа не утверждено и не используется как обязательное требование |
| O-04 | Условия отмены после оплаты, возврата доставки и комиссии, возврат товара после отправки | Запрос отмены и факт возврата денег должны быть разными состояниями; обещание полного возврата пока не утверждено |
| O-05 | Источник статуса доставки и работа с обращениями | Прототип не должен изображать настоящую интеграцию со службой доставки |
| O-06 | Экономическая проверка монетизации и договорные роли реальной платформы | Документация не доказывает готовность продукта к коммерческому запуску |

Дата защиты и дополнительные ограничения оформления не сообщены. Неподтверждённые правила не блокируют подготовку документации: они обозначены явно и не выдаются за принятые условия.
