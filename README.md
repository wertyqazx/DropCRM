# DropCRM

Учебный проект сервиса, который связывает дропшипперов и поставщиков: каталог товаров, наценка, заказ, подтверждение условий, оплата и отправление. Итог работы — интерактивный прототип для трёх ролей.

## Пример для просмотра

Один и тот же заказ **DC-0101** связывает три роли. Дропшиппер выбирает наушники TechSupply за **1 890 ₽** и устанавливает наценку **25%** — цена продажи **2 363 ₽** после округления. Поставщик подтверждает доставку **250 ₽**. Комиссия **37,80 ₽**, сумма оплаты **2 177,80 ₽**. До подтверждения поставщика оплата недоступна.
